## 任务 2：小乌龟
节点是ROS2独立运行小程序，话题是节点之间传递数据的通道。
键盘控制节点往`/turtle1/cmd_vel`话题发送速度指令，小乌龟节点订阅这个话题收到消息，实现移动。节点依靠话题互相通信。

我的额外理解：话题属于松耦合通信。发消息的节点不用管是谁在接收，收消息的节点也不用管是谁发出来的。一个话题可以同时给很多节点接收，一个节点也可以收发好多个话题。这样机器人程序可以拆成一个个独立模块，改其中一个功能，不会弄坏别的功能。
